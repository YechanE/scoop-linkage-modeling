자세는 평행사변형이 지키고,
경로는 두 각의 관계가 만듭니다.

평행사변형 하나는 출력부의 방향을 유지하지만 끝점은 원을 그립니다. 그래서 두 단을 이어 두 회전벡터를 더하고, 목표 궤적이 요구하는 φ와 ψ의 관계를 먼저 찾습니다. 마지막으로 Q–K 링크가 두 각을 묶어 모터 하나로 움직이게 합니다.

01 · GEOMETRY

막대를 잠시 잊고,
벡터 체인만 봅니다.

핵심 중심선은 다섯 점의 연결입니다. 오른쪽 그림의 단계 버튼을 누르면 실제 코드가 좌표를 계산하는 순서로 벡터가 쌓입니다.

  1. 1
    P₁ = O₁ + r₁e(φ)1단 크랭크는 회전한다.
  2. 2
    V₂ = P₁ + mm은 세계 좌표계에서 회전하지 않는다.
  3. 3
    W = V₂ + r₂e(ψ)2단 회전벡터를 더한다.
  4. 4
    TIP = W + cc도 평행사변형 출력에 고정된 상수벡터다.
“병진”은 직선운동이라는 뜻이 아닙니다.

크랭크는 돌아가지만, 평행사변형의 출력 플랫폼은 기울어지지 않고 방향을 유지한 채 이동합니다.

02 · TARGET PATH

링크보다 먼저,
TIP이 가야 할 길을 못박습니다.

손끝은 바닥 위 0.3 mm 높이에서 15 mm 직진한 뒤, 가로 반경 5 mm·세로 반경 10 mm인 1/4 타원을 따라 상승합니다.

직선 진입 x = −Lₛ + Lₛu, z = z₀ 1/4 타원 x = a sinτ, z = z₀ + b(1 − cosτ)

1단 평행사변형만 있으면 출력은 항상

P(φ) = C₀ + r₁e(φ)

이고, 고정점 C₀에서 거리 r₁이 항상 같으므로 원만 그립니다. 직선과 타원이 붙은 목표를 만들려면 두 번째 회전벡터가 필요합니다.

어려운 지점

접합점에서 위치와 접선은 연속이지만 곡률은 0에서 0.4/mm로 즉시 뛵니다. 부드럽게 움직이는 강체 링크가 이 변화를 정확히 따라가기 어려운 이유입니다.

03 · TWO ROTATING VECTORS

두 원운동을 더하면
원이 아닌 경로가 됩니다.

2단을 추가하면 손끝 위치는 다음 한 줄로 정리됩니다.

TIP(φ) = C₀ + r₁e(φ) + r₂e(ψ)

파란 벡터 끝에 주황 벡터를 이어 붙인 끝점이 TIP입니다. 두 벡터의 각도 관계를 바꾸면 끝점의 곡선도 바뀌어집니다.

ψ = +φ같이 회전

두 벡터가 한 벡터처럼 움직여 원을 그립니다.

ψ = −φ반대로 회전

반축 r₁+r₂, |r₁−r₂|인 정확한 타원이 됩니다.

r₁ = r₂, ψ = −φCardan 직선

타원의 한 반축이 0이 되어 정확한 직선이 됩니다.

중요: 각도 “비”는 보통 한 숫자가 아닙니다.

ψ=kφ는 원·타원 같은 특수 예제입니다. 임의의 목표 궤적에서는 φ가 변할 때 ψ도 비선형으로 변하므로 관계 전체를 ψ=f(φ)로 저장합니다. 아직은 두 각을 독립적으로 정하는 2 DOF입니다.

04 · EXACT INVERSE KINEMATICS

Q–K를 만들기 전에,
이상적인 각도를 먼저 구합니다.

목표점 P와 기구 중심 C₀가 주어지면, 다음은 중심 C₀의 반지름 r₁ 원과 목표점 P의 반지름 r₂ 원의 교점 문제입니다.

1

v = P − C₀, d = |v|목표점을 중심 기준 벡터로 바꾼다.

2

cos α = (d²+r₁²−r₂²)/(2dr₁)r₁, r₂, d 삼각형에 코사인 법칙을 쓴다.

3

φ = atan2(vz,vx) ± α두 팔꿈치 분기 중 행정 내내 같은 쪽을 쓴다.

4

ψ = atan2(v − r₁e(φ))남은 r₂ 벡터의 방향을 읽는다.

목표 경로의 모든 점에서 이 계산을 반복하면 오차가 없는 ψrequired(φ)를 얻습니다. 여기까지는 Q, K, L이 한 번도 등장하지 않습니다.

이것이 함수 생성의 “정답지”입니다.

이제 실제 링크가 이 각도 관계를 얼마나 잘 따라하는지 비교하면 됩니다.

05 · CLOSED-LOOP FUNCTION GENERATOR

Q–K 링크는 경로보다
“각도 함수”를 만듭니다.

K는 2단 크랭크에 붙은 핀이고, Q는 지면 고정점입니다. 둘을 길이 L인 막대로 연결하면 다음 하나의 조건이 생깁니다.

K = V₂ + ρe(ψ+β), |K−Q| = L

원래 독립이던 φ, ψ에 스칼라 조건 하나가 추가되어 2 DOF가 1 DOF가 됩니다. φ를 정하면 ψ는 삼각형을 닫을 수 있는 각도로 강제됩니다.

Q–V₂–K 삼각형 C = (L²−ρ²−s²)/(2ρs) ψ = σ − β + χ cos⁻¹(C) s = |V₂−Q|, σ = atan2(V₂−Q), χ = ±1

V₂가 φ에 따라 이동하므로 s와 σ도 φ의 함수입니다. 결국 Q, ρ, β, L을 고르는 것은 다음 곡선의 모양을 고르는 일입니다.

ψlinkage(φ; Q,ρ,β,L)≈ψrequired(φ)

06 · FINAL MODEL · q₁ → TIP

결국 모터각 q₁ 하나로
TIP 좌표를 직접 계산합니다.

맞습니다. 이 기구의 최종 모델은 q₁을 입력하면 q₂가 폐루프에서 자동으로 정해지고, 이어서 TIP의 x·z 좌표가 나오는 하나의 함수입니다. 아래에서 중간 변수를 하나도 생략하지 않고 연결합니다.

q₁ = φ모터가 직접 돌리는 입력각 → q₂(q₁) = ψ(φ)Q–K 링크가 자동으로 만드는 각 → pTIP(q₁)최종 손끝 좌표
표기 주의

소문자 q₁은 회전 조인트의 각도이고, 도면의 대문자 Q는 움직이지 않는 고정핀입니다. 서로 다른 기호입니다.

01
INPUTq₁으로 1단 끝점 V₂를 계산

평행사변형 때문에 플랫폼 오프셋 m은 회전하지 않고 그대로 더해집니다.

e(θ) = [cos θ, sin θ]ᵀ V₂(q₁) = O₁ + r₁e(q₁) + m
V₂x = O₁x + mₓ + r₁ cos q₁ V₂z = O₁z + m_z + r₁ sin q₁
02
CLOSURE INPUT고정핀 Q에서 V₂까지의 벡터

q₁이 바뀌면 V₂가 움직이므로 삼각형 Q–V₂–K의 한 변과 방향이 함께 바뀝니다.

d(q₁) = V₂(q₁) − Q = [dₓ, d_z]ᵀ s(q₁) = √(dₓ²+d_z²) σ(q₁) = atan2(d_z,dₓ)
03
LOOP CLOSURE코사인 법칙으로 q₂(q₁)를 분리

K=V₂+ρe(q₂+β)와 |K−Q|=L을 제곱해 전개하면 다음 식이 나옵니다.

L² = s²+ρ²+2ρs cos(q₂+β−σ) C(q₁) = (L²−ρ²−s(q₁)²)/(2ρs(q₁)) q₂(q₁) = σ(q₁)−β+χ cos⁻¹(C(q₁))

χ=+1 또는 −1은 조립 분기이며, 실제 링크가 닫히려면 |C(q₁)|≤1이어야 합니다.

04
FORWARD KINEMATICSq₂를 대입해 TIP 좌표 완성

2단 회전벡터를 더한 뒤, 자세가 고정된 출력 플랫폼의 오프셋 c를 그대로 더합니다.

pTIP(q₁) = V₂(q₁)+r₂e(q₂(q₁))+c
pTIP(q₁) =
O₁x+mₓ+cₓ+r₁cos q₁+r₂cos(q₂(q₁)) O₁z+m_z+c_z+r₁sin q₁+r₂sin(q₂(q₁))

c에 회전행렬을 곱하지 않는 이유는 TIP이 2단 크랭크가 아니라 방향이 유지되는 평행사변형 출력부에 붙어 있기 때문입니다.

q₁ → q₂ → TIP최종 모델을 한 각으로 실행
s(q₁)— C(q₁)— 자동 q₂— dq₂/dq₁— |dp/dq₁|— TIP(q₁)—
화살표는 q₁이 증가할 때의 순간 이동방향 dpTIP/dq₁

ONE MORE STEP · VELOCITY

q₁에 대해 미분하면 TIP 속도까지 나옵니다.

여기서 ′ = d/dq₁입니다. 모터 각속도가 q̇₁이면, 오른쪽의 위치식을 q₁로 미분한 뒤 q̇₁을 곱하면 실제 TIP 속도가 됩니다.

행정 방향현재 설계는 q₁이 139.25°에서 17.75°로 감소합니다. 따라서 실제 진행방향은 그림의 +q₁ 접선과 반대입니다.
e⊥(θ) = [−sin θ, cos θ]ᵀ d′(q₁) = r₁e⊥(q₁) = [−r₁sin q₁, r₁cos q₁]ᵀ s′ = (dₓd′ₓ+d_zd′_z)/s σ′ = (dₓd′_z−d_zd′ₓ)/s² C′ = −s′/(2ρ) · [1+(L²−ρ²)/s²] q₂′ = σ′−χC′/√(1−C²) dpTIP/dq₁ = r₁e⊥(q₁)+r₂q₂′e⊥(q₂) vTIP = (dpTIP/dq₁) q̇₁
