# Scoop Linkage Studio

최적화된 2단 병진 링크 기구를 브라우저에서 직접 편집하는 로컬 도구다. 설치할 프런트엔드 패키지나 인터넷 연결은 없다.

## 실행

프로젝트 루트의 `START_INTERACTIVE_EDITOR.bat`을 더블클릭한다. 기본 브라우저에서 `http://127.0.0.1:8765`가 열린다. 터미널을 닫으면 서버도 종료된다.

직접 실행하려면:

```powershell
.\.venv\Scripts\python.exe .\web_editor\serve.py
```

브라우저에서 `modeling_walkthrough.html`을 열면 목표 경로 → 역기구학 →
Q–K 폐루프 → 실제 TIP 경로 순서의 그림·애니메이션 학습 페이지가 열린다.

## 편집 규칙

- `O1`, `Q`: 두 고정축 위치를 바꾼다.
- `P1`: 1단 크랭크 길이와 입력 위상을 바꾼다.
- `V2`: 1단 플랫폼에서 2단 축까지의 오프셋을 바꾼다.
- `K`: 연결 핀의 반경, 상대각, Q-K 링크 길이를 바꾼다.
- `W`: 2단 링크 길이와 K의 상대 위상을 바꾼다.
- `TIP`: W에서 손끝까지의 오프셋을 바꾼다.
- `O1b`, `P1b`: 1단 평행사변형 폭을 바꾼다.
- `V2b`, `Wb`: 2단 평행사변형 폭을 바꾼다.

청록색은 현재 궤적, 보라색 점선은 비교 기준, 빨간색은 목표 직선+1/4 타원 경로다. `현재를 비교 기준으로` 버튼으로 비교 기준을 언제든 갱신할 수 있다.

브라우저는 평면 중심선 기구학과 폐루프 조립 가능성, 사점 여유를 실시간 계산한다. 출력물의 3차원 간섭과 강성은 별도 CAD 검증 대상이다.
